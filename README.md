## 🛠️ Technology Stack & Standards
- **Core Languages**: Modern HTML5 (Semantic & Accessible), CSS3 (Custom Properties, Flexbox, Grid)
- **Design Philosophy**: Mobile-First, Accessible (ARIA & WCAG compliant), Fluid typography & spacing
- **Dev Environment**: VS Code, Live Server, Prettier, ESLint, Node.js v20.x, Git & GitHub
- **Git Hygiene**: Strict `.gitignore` policy, semantic atomic commits (`feat:`, `chore:`, `docs:`)

## 🚀 Running Any Project Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/ronit-ahuja-04/Linkific-Tasks.git
   cd Linkific-Tasks
   ```
2. Open in VS Code:
   ```bash
   code .
   ```
3. Navigate to any project folder (e.g., `Day-01/04-portfolio/`) and right-click `index.html` → **"Open with Live Server"**.
