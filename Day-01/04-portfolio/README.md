# Project 04: Capstone Portfolio & Day 1 Training Hub

A single-page personal portfolio landing page for **Ronit Ahuja** (Full Stack Developer & Linkific Trainee), featuring an interactive **Day 1 Training Hub** with a live component switcher as part of **Day 1: HTML5, CSS3 & Responsive Design Training** at Linkific.

---

## 🌟 Key Features
- **Semantic HTML5 & Accessibility**:
  - Full landmark hierarchy (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
  - Accessible button states, skip links, and semantic heading structure.
- **Eye-Gazing Brownie Points Feature: Interactive Training Hub**:
  - Embedded responsive switcher allowing visitors to preview all 3 Day 1 practice projects (`01-responsive-nav`, `02-card-grid`, and `03-blog-layout`) without leaving the page.
  - Interactive status badges, code breakdown viewer, and fullscreen launch buttons.
- **Ambient Mouse Spotlight Glow**:
  - Subtle interactive radial-gradient follower tracking cursor coordinates across cards.
- **Comprehensive Professional Sections**:
  - Hero Section with live Linkific training metrics.
  - About Me & Engineering Philosophy (VESIT Mumbai IT student).
  - Production Projects Showcase (VESIT AMS, Kingstar Enterprises, FlowLane, Budgetify).
  - Technical Skills Matrix with animated percentage meters.
  - Experience & Education dual-column timeline.
  - Responsive contact form with anti-spam honeypot.

---

## 📐 Responsive Breakpoints Tested
| Viewport | Behavior |
| :--- | :--- |
| **Mobile (`375px`)** | Collapsible navigation toggle, stacked metric cards, single-column about & contact layout, optimized 420px training console |
| **Tablet (`768px`)** | Fluid 2-column metrics, side-by-side timeline columns, responsive console controls |
| **Desktop (`1200px+`)** | Full sticky desktop header, 320px fixed author card, 520px high-fidelity training simulator |

---

## 💡 Key Learnings & Takeaways
1. **Component Synthesis**: Building individual focused components (Nav, Card Grid, Blog) first allowed effortless integration into the capstone portfolio.
2. **CSS Variables for Systemic Design**: Setting clear tokens for surfaces, borders, gradients, and font families makes adjusting themes and contrast effortless.
3. **Progressive Interactive Polish**: Adding ambient cursor lighting and tabbed iframe previews adds tremendous professional polish without introducing heavy framework dependencies.
