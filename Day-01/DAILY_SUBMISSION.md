### Section 2: Key Technical Learnings (~2 minutes)
> *"My biggest technical takeaways from today were:*
> - *First, **Pure CSS State Management**: Achieving rich interactivity—like the mobile slide-down drawer and instant multi-category project filtering—using pure CSS pseudo-classes like `:checked`, `:not()`, and the general sibling combinator `~`. This proves how much can be achieved without JavaScript overhead.*
> - *Second, **The Synergy of Flexbox and CSS Grid**: Using Flexbox for single-dimensional component alignment (such as navbar items and card footer tags) while using CSS Grid for 2D responsive structures that adapt smoothly from 1 column on mobile to 2 on tablet and 3 on desktop.*
> - *Third, **Strict Mobile-First Progressive Enhancement**: Writing default styles for mobile viewports under 768px without media queries, then progressively enhancing for tablet and desktop using `min-width` queries.*
> - *And fourth, **Vector Precision**: Solving sub-pixel icon rendering on retina screens by switching to precise Font Awesome vector geometries for GitLab and LinkedIn."*
